# SchlauWutzie K.I. V22.12

## Ziel
Ein einziges 9:16-Video aus:
- geladenem Bild **oder** geladenem MP4 als Hintergrund
- Untertiteln aus dem bisherigen Textvideo-Workflow
- **nur** der zentralen SchlauWutzie-K.I.-Animation: Gehirn + HUD + Waveform + „SCHLAUWUTZIE K.I.“
- Waveform reagiert auf die tatsächliche Sprachlautstärke

Kein SchlauWutzie-Kopf und keine komplette Branding-Grafik als untere Fläche.

## Neu
- `VIDEO LADEN` ergänzt.
- Bild und Video werden auf 1080x1920 / 9:16 angepasst.
- Die KI-Animation wird als transparente Ebene in die laufende Bild-/Videokomposition integriert.
- Die Waveform wird framegenau aus der TTS-/Audio-Amplitude gesteuert.
- Der vorhandene Untertitel-Workflow bleibt danach erhalten.

## Test
V22.12 wurde mit einem 1080x1920-MP4-Hintergrund und echter Audiospur gerendert.
