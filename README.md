# SchlauWutzie K.I. – Video Studio V22.3 FINAL

**Dies ist die einzige Finalversion.** Ältere V22.3-Builds dürfen nicht als Referenz verwendet werden.

## FINAL-Regeln
- Untertitel: große, mobile-lesbare V22.3-Darstellung (Font 68), kurze Blöcke, max. 2 Zeilen, DTW-synchronisiert.
- Stimme: Microsoft OneCore / Microsoft Stefan, ohne TTS-Fallback.
- Bild oder MP4 kann als Quelle geladen werden.
- Bei einem neuen Bild bleibt das Motiv erhalten und bekommt denselben SchlauWutzie-K.I.-Animationsstil.
- Bei einem neuen MP4 bleibt die Videobewegung erhalten; die gleiche blau-goldene, sprachreaktive SchlauWutzie-K.I.-Animation wird darübergelegt.
- Die Animation reagiert auf die Audiospur. Beim MP4 wird die eigene Audiospur des MP4 verwendet.
- Fest eingebranntes Referenz-Branding: **SchlauWutzie K.I.** — niemals „K.I. ONLINE“.
- Die hochgeladene Referenzoptik wird als feste Design-Signatur in jedes gerenderte Bild/MP4 eingebrannt.
- Blau-/Gold-HUD, Equalizer/Lichtbewegung und zentrale Markenplakette folgen der bisherigen Referenzoptik.

## Bedienung
1. Text einfügen.
2. Bild laden **oder** „MP4 LADEN + SCHLAUWUTZIE-ANIMATION“ verwenden.
3. StefanM erzeugen bzw. bei MP4 die eigene Tonspur verwenden.
4. Deutsche Auto-Untertitel erzeugen.
5. MP4 speichern.
